# Golden scene: the workshop key

This example shows how one shared production contract compiles into three different model profiles. It is intentionally fictional and contains no external assets.

Historical 0.1-alpha teaching fixture: these records are not valid formal acceptance packets for 0.2. The current [portable workflow](../public-workflow/README.md) explains both method choices, evidence limits and state transitions. Adding an insert changes coverage and requires a revised shot contract; it must not be called a one-variable prompt reroll. The labels below preserve the original teaching history, not an executed production run.
