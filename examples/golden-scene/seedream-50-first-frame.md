# Seedream 5.0 Pro first-frame prompt

模型：Seedream 5.0 Pro。图片制作任务：生成钥匙交接镜头的唯一首帧，供后续视频使用。

参考职责：`@图片1` 只负责姐姐的面部、发型和体型，不带入原图背景与光线；`@图片2` 只负责弟弟的面部、发型和体型；`@图片3` 只负责修理铺空间结构、卷帘门、右侧工具墙和左侧工作台；`@图片4` 只负责姐姐深灰色防水外套和右腕旧红绳；`@图片5` 只负责弟弟靛蓝色无文字工作服。所有参考均不得改变其他素材负责的维度。

摄影机位于工作台短边、两人轴线同一侧，视角略偏姐姐一侧，眼平高度，50mm 中近景构图，两人的上半身和双手完整可见。姐姐在画面右侧，弟弟在画面左侧，隔着工作台相对站立；姐姐右手仍在外套口袋里握住黄铜钥匙，弟弟左手自然垂在工作台边，动作尚未开始。

背景与地标：姐姐背后必须看见狭窄卷帘门和一条冷色雨光门缝；弟弟背后必须看见暖色工具墙；左侧工作台边缘形成明确透视线。暖色吊灯从工作台上方照亮手部，门缝冷光只做轮廓分离，保留真实皮肤、旧金属和磨损木材质感。

构图保留两人手部之间的动作空间。禁止增加第三个人、交换左右站位、镜像红绳、把钥匙放到错误手中、重设计房间、带入参考图背景、生成字幕或服装文字。

验收检查：两人身份和服装正确；姐姐右侧、弟弟左侧；姐姐右腕红绳和右手口袋状态正确；卷帘门、工具墙、工作台三个地标证明机位方向；手部无遮挡并留有钥匙交接空间。
