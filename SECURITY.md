# Security policy

Shotloom is an instruction-based Agent Skill with optional local checking scripts. It does not require network access, credentials, API keys, or payment information.

## Report privately

Do not open a public issue if you discover instructions or scripts that could expose local files, credentials, private media, or unsafe external actions. Contact the repository maintainer through GitHub's private security advisory feature.

## Scope

Security reports may include unsafe file traversal, credential collection, hidden network activity, installer overwrite behavior, prompt-injection paths through untrusted references, or instructions that misrepresent external actions as completed.
