# Model routing and evidence

Shotloom provides model-specific guidance, not provider integration. Follow [generation planning](../modules/generation/WORKFLOW.md) and [environment](environment.md). Use only the exact task/model/version requested or authorized. Selection advice concerns models, not websites, accounts or providers.

| Resource | Coverage in this package |
| --- | --- |
| [MiniMax H3](../modules/generation/references/minimax-h3.md) | Native mode/grammar, references, timing and sound; H3 Max is not presumed equivalent |
| [Seedance 2.0](../modules/generation/references/seedance-20.md) | Full-version native planning; Mini/Fast are separate |
| [Seedance 2.5](../modules/generation/references/seedance-25.md) | Generation, long-form, edit and extension methods with dated source/conflict register |
| [Seedream 5.0](models/seedream-50.md) | Retained alpha image-generation/editing profile; historical source baseline |
| [Kling 3.0 series](../modules/generation/references/kling-3-series.md) | Video, image, Omni, Turbo and motion-control branches |
| [Wan 3.0](../modules/generation/references/wan-3.md) | Mode-specific generation/reference/edit/extension planning |
| [Image models](../modules/generation/references/image-platforms.md) | Versioned Midjourney, Nano Banana and GPT Image 2.5 documentation snapshots |
| [Google video](../modules/generation/references/google-video.md), [Runway](../modules/generation/references/runway-gen45.md) | Limited guidance requiring exact-version verification, not equivalent to a complete adapter |
| Unlisted or unresolved model | Model-neutral contract with explicit adapter gap; never rename another model's rules |

This table records bundled guidance, not current availability or measured quality. See [manual authority](../modules/generation/references/model-manual-authority.md). Numerical limits, modes and aliases require current primary evidence when consequential. No remote call, paid test or host discovery is needed merely to draft a labeled native plan.

Video comparisons use [task-based selection](../modules/generation/references/video-model-selection.md); image/audio do not inherit video gates. Compare material input/control requirements, creative risk and applicable evidence separately. A model maximum is not a target duration.

Compile each model independently from the same source lock. Unknown destination bindings remain intended settings for user verification. Existing alpha model paths remain compatibility routes, not competing specifications.
