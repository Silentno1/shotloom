# Scoped editing and compositing tool choice

Use only when a concrete task needs an execution route or the existing route is inadequate. Keep a working route for unchanged requirements. Choose the required capability first, then an already available, authorized local tool. This is a decision aid for the current environment, not a mandatory software stack, installation workflow or replacement for the director/model contracts. If no suitable execution capability is available, return a reproducible plan and the unverified dimensions; do not require a plugin to continue planning.

## Choose the smallest adequate operation

| Actual need | Candidate route, if available and verified | Boundary |
| --- | --- | --- |
| Select/reorder/trim existing approved media, mix available tracks, conform/export | Existing local editor or media tools, with transcript assistance only when needed | Speech boundaries are aids, not automatic story cuts. Preserve reactions, silence, offscreen action, source quality and actual sound/picture mappings. |
| Exact text, captions, title cards, diagrams, graphic animation or repeated layouts | Existing local compositor or deterministic graphics renderer; choose by the required output and current project | Deterministic layer timing does not guarantee story quality, pixel identity across environments or generative character performance. Do not impose the template's look. |
| A display inside a filmed/generated scene | Focused content asset plus the established compositor, if tracking, perspective and occlusion are feasible; a permitted insert can be an alternative | A graphics renderer alone does not prove tracked screen replacement. Account for motion blur, reflections, masks and room/device sound when material. Do not replace a required spatial relationship with a flat overlay silently. |
| Timing/wording correction of existing captions or a local sound anchor | [Caption conform](subtitle-conform.md) or [output sync](output-sync-calibration.md) using current tools | A local fix is not authority to re-transcribe everything, rebuild the cut or replace all native audio. |
| Missing embodied performance, required visible interaction, identity or story event that existing footage cannot supply | Diagnose with review and return the specific unresolved dependency to director/generation | More graphics, cropped talking faces or louder sound cannot be assumed to restore it. Return a scoped model-native prompt plan when needed; the user performs external generation. This route never uploads or calls a generation service. |

Optional tool-specific examples include `video-use`, `remotion-best-practices` and `hyperframes`, but none is a package dependency. Consider one only when it is available in the current session and supports the needed local operation; an equivalent authorized local tool is also eligible. Read the chosen skill's current instructions and the relevant mode, not all tool manuals. This guide names no guaranteed command, provider or version and does not authorize installation, package updates, background services, uploads or paid APIs. An existing installation still needs the relevant runtime/operation capability checked before use; a missing capability is reported, not quietly substituted with an inferior output.

## Handoff only the necessary contract

Reuse the current approved scope: input files/hashes and selected ranges; audio/picture time origin and rate mapping; intended output/layer role; duration, dimensions and timebase; alpha/compositing needs; text and look locks; sound treatment and sync anchors; output location and review criteria. Pass only fields material to this operation, without creating another universal packet.

Keep internal asset timing, composition time and final-cut placement distinct. State whether an overlay includes audio, whether captions are preview/sidecar/burned-in, and whether a result is a transparent layer, flattened candidate or final master. Preserve editable sources when the workflow requires later revisions. Do not claim transparency, editable export, seamless alpha edges or reproducible rendering without verifying the actual output.

All frames, layers and sound keep their approved appearance family; 2D, 3D, photographic, stop-motion, mixed and custom work are eligible according to actual tool/source support. A local graphic layer does not relabel the whole work or change upload category. Read [embedded-media direction](../../director/references/embedded-media-direction.md) when the boundary into a screen's content affects the scene.

## Preview, inspect, then integrate within authorization

For an uncertain composite or retime, use the smallest useful authorized local preview to test the affected range and boundaries. A simple established trim need not trigger a separate proof-of-concept. Integrating a new layer changes the export: check actual typography/occlusion/edges, timing, color/cadence and applicable sound in the resulting file, not only the standalone component or editor view.

If a route fails, distinguish missing runtime capability, incorrect operation, inadequate source and a failed creative design. Keep the original material and report the scoped alternative and its effect. Do not install another system or spend credits simply because the preferred tool failed. A local render has time/resource cost even when it consumes no generation credits; no blanket savings guarantee.

## Provenance and exclusions

This routing adapts the separation of editable composition, source media and production decisions in [Remotion](https://github.com/remotion-dev/remotion), [HyperFrames](https://github.com/heygen-com/hyperframes), [video-use](https://github.com/browser-use/video-use) and [OpenMontage](https://github.com/calesthio/OpenMontage/blob/main/AGENT_GUIDE.md), reviewed 2026-10-05. No third-party runtime/code was bundled. Upstream defaults about audio-first cuts, forced multi-agent work, repeated approvals, global style, automatic installation or passing unresolved critical defects do not replace this project's scope and acceptance rules.
