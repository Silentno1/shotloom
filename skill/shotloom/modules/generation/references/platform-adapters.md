# Platform adapter registry

This compact registry records boundaries, not full manuals. Verify exact model and interface before using a changing fact.

## Seedance / Seedream

Use the user's exact active version and official manual. Keep image, video and audio roles separate. Seedance syntax and timing never become H3 syntax. A platform maximum is not a target duration. Exact text, dialogue and interface behavior require direct output review.

## Kling / 可灵 3.0 series

Use [kling-3-series.md](kling-3-series.md) to select video, image, Omni/O3, Turbo or motion control. Read the corresponding mode and exact destination evidence; ordinary 3.0, Omni editing and action transfer do not share one input contract. Versions without a maintained adapter require their own verified source scope; absence is not a user-wide blacklist. A catalog alias is not a universal API name, and a manual capability is not proof that the selected destination exposes it.

## Google video

Keep Gemini video paths and Veo variants separate. Verify current model name, task, durations, aspect ratios, audio, reference and extension behavior in first-party documentation. Do not preserve the retired claim that an unspecified “Omni” path has no duration limit. Current official documentation for the selected path governs.

## Wan 3.0 video

Use [wan-3.md](wan-3.md) and its [dated source register](wan-3-sources.md). Separate text generation, first/last frames, multimodal reference, editing, extension and file/webpage input. Frame inputs and reference groups are mutually exclusive; prompt rewriting is not video extension. Preserve duration ambiguities instead of borrowing another model's semantics. No third-party execution or output quality is implied by the official manual.

## Runway

Verify the exact model generation path. For image-to-video, the input frame owns appearance and starting composition; prompt motion deltas. For text-to-video, describe the visible world and movement. Timestamp instructions mark real changes, not decorative subdivisions.

## Image models

Route via [image-platforms.md](image-platforms.md) to Midjourney's versioned branches, Nano Banana's exact variants or GPT Image 2.5 Flare/Sunburst. Their reference systems, edit contracts and output controls differ. Do not rename one generic prompt. Exact text and identity support are capabilities to verify on actual outputs, not guarantees or authorization for automatic paid tests.

## Unverified platforms

Use a generic visible-state/action/camera/endpoint contract and explicitly state that limits and syntax are pending current verification. Never invent a proprietary adapter.
