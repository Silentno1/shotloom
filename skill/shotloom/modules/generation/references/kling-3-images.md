# 可灵 IMAGE 3.0 与 IMAGE 3.0 Omni

先读 [系列路由](kling-3-series.md)。只用于静态生成/改图/组图；不套视频时长、原生音频、多镜开关或 H3 结构。依据为 [官方登记](kling-3-sources.md) K3-I、K3-IO、K3-E。官方能力不等于当前宿主已有入口。

## IMAGE 3.0：生成、编辑与多参考

采用自然语言表达目标；根据任务区分：

- 文生：所需单幅画面的主体状态、空间关系、景别/视角、焦点、光线、色调及已选画风。只写这个瞬间能看见的动作/表情，不把动态发展写成一张图必须同时出现多个动作。
- 单图编辑：明确改哪个对象/区域、改成什么、哪些已批准内容保持；必要时明确局部受影响的光照/遮挡，不用“其余不变”掩盖物理冲突。
- 多参考：对身份、服装/道具、场景、布局、风格分别指派实际图号/标签，声明允许和禁止的迁移。不能把风格图的人物、姿态或故事一并移入。
- 多视图/镜位变化：说明新视角和可见关键特征；未知背面/遮挡面仍是设计推断，结果需审批，不因生成器补全就写入正式资产。

官方短改图例子是局部任务，不是所有生产提示词的字数上限。表演参考中的“悲伤”“微笑”也不替代已批准的具体眼神、嘴角、身体姿态与强度。静态通过不能证明情绪转折、泪水运动、动作节奏、皮肤/纹理随运动稳定。

## IMAGE 3.0 Omni：单幅与系列组图

可用于分镜预演、角色/场景设计、系列画面与批量修改；先确定输出类型，不默认打开组图。

- 单幅按静态合同编译；不因手册以电影画面示范就强制写实摄影或复刻示例影片。
- 叙事组图：继承导演已经批准的分镜顺序、每张图的叙事作用、人物/场景参考、画面变化及不变量；不是让模型重新决定剧情或自选导演。
- 非叙事组图：区分多个角度/状态与不同方案；任务要同一角色多视图时不能变成多个角色候选。
- 固定交付张数时使用真实的指定张数控件；“智能/自动张数”只在范围与计费都允许时使用，不能自动扩大批次。
- 明确是 **多个独立文件** 还是 **单文件多宫格**。没有已验证的导出形式，不把“6 个镜头”当成一定返回 6 张可独立绑定的素材；每张/每格都要有可回读身份与审查结果。
- 批量编辑逐张确认保留项、修改项及匹配关系，不能用一张成功样例替整组通过。组图中的人物、轴线、光向、道具状态和空间拓扑仍逐张核对。

给定导演/已审分镜时，模型的构图建议只是候选；不自动替换权力关系、注意焦点或揭示顺序。镜头焦段/光圈等描述是目标画面语言，不等于相机元数据或精确透视已被验证。

## 规格、绑定与交付

参考数、输出张数、组图开关、输出分辨率/比例、裁切和计费按具体入口核对；官网的参考配额不无条件复制到第三方。2K/4K 是实际输出选项时才填写，提示词里“8K”不升级输出像素。

本包不记录任何用户的已安装模型目录。可交付本型号的原生图片方案；用户入口是否提供它、标签怎样绑定均独立核对。不能把视频模式当作图片模型，或擅自换模型；Shotloom 不执行上传或生成。

生成后逐幅检查资产身份/设计、手部与接触、文字、布局/视线/光向、所选画风和编辑保留区。只有审批后的具体文件/候选版本才可作为后续视频输入；“组图成功”不等于整组被批准，更不等于成片连续性通过。
