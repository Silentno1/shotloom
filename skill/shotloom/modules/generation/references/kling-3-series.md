# 可灵 3.0 系列：按模型、模式和宿主编译

适配基线：2026-10-02 的资料快照。用途是编写制作计划，不是重新导演、自动换模型或证明质量。当前只维护本文件列明的 3.0 分支；其他版本需要独立适配及当前依据，不受某个人的模型白名单或等待策略约束，不自动启用或测试。

## 只读当前需要的分支

| 目标 | 必读分支 | 候选依据与主要风险 |
| --- | --- | --- |
| 文生视频、首帧驱动、首尾帧、带对白的单镜/多镜 | [视频适配](kling-3-video.md)的普通 3.0 分支 | 用现有构图/主体约束叙事；多镜能力不等于逐帧可控 |
| 多参考组合、主体复用、已有视频局部修改 | 同文件 Omni 分支 | 参考角色与修改范围可分配；输入视频会改变限制，不能混同主体视频 |
| 3.0 Turbo | 同文件 Turbo 分支 | 在控制条件满足后才比较速度/费用；不假定更便宜、质量相同或具备 Omni 的全部控制 |
| 已有单人动作/表演参考 | 同文件动作控制分支 | 动作参考有用时才候选；不是多人打斗编舞器 |
| 图片生成/局部修改、多视图、连续组图 | [图片适配](kling-3-images.md) | 静态资产和画面预演；不能验证动态连续性 |

官方依据见 [来源与冲突登记](kling-3-sources.md)。新模式、重要事实变化时核对原始章节。实际标签和控件用 [用户目的地核对](destination-bindings.md)，不继承个人平台快照，也不接入服务。

## 身份识别

- 记录媒介、正式名称/版本、宿主、实际 modelKey、模式和核对日期。`3.0` 单独不能区分图片/视频；`Omni` 单独不能区分代际。
- O3 等别名仅在用户提供的确切入口证据下映射；不能据字符串后缀推断版本或模式。本包不内置个人平台映射表。
- 普通 3.0、Omni、Turbo、动作控制各自读模式，不因都带 3.0 共用全部能力；IMAGE 3.0 Omni 也不是 VIDEO 3.0 Omni。
- 模型候选以必要输入/控制/规格为先，成本以当前报价为准。只接入选项，不批量制作多模型或多导演对照；改变已锁定模型、付费测试和新增服务仍受原授权约束。

## 通用编译顺序（继承既有工作流，不重复建档）

1. 复用 source lock、已选导演的方法合同、独立的 appearance_family、参考审批、对白/文字和声音归属。名字和片名不代替方法，不照搬官方演示的剧情、长镜头、音乐或写实画风。
2. 先选实际任务：生成新内容、指定起终态、参考主体、编辑已有片段或迁移动作。逐项分配“参考实际提供什么、文字补什么、真实控件负责什么、后期负责什么”。
3. 只在已绑定且查验的素材里委托信息；生成的人物补视图仍是待验候选，不能自动替代批准资产。主体库绑定不能替代服装、道具、站位和出场状态的连续性核对。
4. 按本模式写可粘贴文本。预期顺序、模式/开关、素材及未验证项放在提示词外，由用户核对；官方示例和用户入口的引用格式不能互换。Shotloom 不上传、提交或报价。
5. 保留导演已决定的事件触发、目光目标、肢体/表情发展、力度与节拍、机位/景别变化和退出状态。不存在“可灵必须极短提示词”或“必须写满 15 秒”的规则。
6. 沿用 source-lock、声音、平台证据、实际操作对照和素材几何检查；本系列暂没有专有提示词语义校验器，不把 H3 校验或 generic 模式当作可灵验证。`operation_reconciliation_check.py`只适用于其视频结构范围，不能拿它验证静态组图。

中文可作为默认交付语言，精确台词/文字保留源语言。模型提示词语言偏好只有在对应官方证据或实际对照支持时才调整；不假定英文一定优于中文。形式正确、官方示例和平台接受请求均不证明画面、表演或打击感达标。

## 声音与风格边界

原生声音、输入视频原声、主体绑定音色、后配轨是四个不同来源。先决定 audible ownership，再选真实开关；不因默认开启就保留整条声轨。原生对白/接触声可按批准方案保留，跨段环境底、旁人闲聊、配乐若为 `post_only` 则不写成生成请求。需要画面同步的口型、动作或台词锚点按既有 picture-sync 策略处理；提示词不提环境声不保证模型不会生成。

模型/模式不能选择作品画风。遵循统一的[画风激活范围](../../visual-design/references/appearance-family-routing.md)：全局批准三渲二，或 `mixed_media` 中明确批准的局部三渲二对象/区间，才在对应范围加载编译器；不改变混合根分类、不污染其他层、不因此增加生成次数。动作参考的人脸/衣服/材质不自动转移，风格参考也不自动带入它的故事、机位、角色或声音。

## 提交前与结果审查

逐项查实际模型/模式、输入类型与顺序、主体数及共享配额、时长与分镜总量、比例/清晰度、原生/原声开关、报价及授权。缺少硬要求的控制时，报告控制缺口；不静默缩短动作、删对白、换人、转画风或降验收标准。

成片仍交审片技能：核对真实时长与切点、身份及空间接续、视线/肢体反应、动作接触与受力、音画同步和声音层、结束状态。多镜片段逐镜审，编辑片段比较修改区与保留区；不能只看首尾帧。未授权生成时止于适配/提示词，不启动制作。
