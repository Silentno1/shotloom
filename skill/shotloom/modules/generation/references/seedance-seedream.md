# Seedance and Seedream adapter boundary

Use the exact active version and its authoritative manual. Seedance 2.0 craft does not override Seedance 2.5 rules. For 2.5, the Jimeng official manual is primary; conflicting legacy third-party guidance is superseded, not averaged with it. See [seedance-25-sources.md](seedance-25-sources.md) for the source order and documented mode envelopes.

For video, load [seedance-20.md](seedance-20.md) or [seedance-25.md](seedance-25.md), with provenance in [model-manual-authority.md](model-manual-authority.md). Distinguish full/Mini/Fast and input mode before compiling; select host bindings at execution or when a prompt is explicitly destined for that host. An unspecified/unavailable third-party interface does not block a model-native prompt plan. Do not derive a single cross-version prompt template from external canvas examples. Seedream remains the static-image branch below; video timing and syntax are not its rules.

Do not preserve an undocumented local duration or capability as a permanent Seedance 2.5 fact. Record the exact surface, model label, observation date and screenshot/manual path before using an interface claim such as a 4–30 second envelope or multimodal references. Recheck after interface/model changes. A displayed maximum is a ceiling, not a target. Use continuous playback-order timing; each interval corresponds to a trigger or state change, not an equal grid.

Seedream image generation/editing carries static appearance and exact starting geometry. Assign each reference one role. Exact small text and complex layout remain review requirements, not guarantees.

Keep the upload list and operator steps outside the pasteable prompt; keep platform-required reference labels inside it. Never transfer Seedance `@` labels into H3.

Use the shared [appearance activation scope](../../visual-design/references/appearance-family-routing.md) to load [three-render-two-compilation.md](three-render-two-compilation.md) for the whole operation or only an approved local owner inside `mixed_media`. State the stable lock once, then current time-segment deltas in the continuous timeline; name the local owner and keep other layers unchanged. Do not repeat all eight dimensions in every interval, relabel the composite or require an extra generation.
