# 视频模型选型：先看制作要求，再看证据

版本：video-model-routing-v1.1，2026-10-02。用于已有视频模型的候选比较、初次选择或有理由的重新选型；不是评分排行榜、自动调用器或成片质量保证。模型画像见 [video-model-profiles.md](video-model-profiles.md)，原生能力及写法仍以 [官方手册索引](model-manual-authority.md) 和确切适配器为准。

## 范围与复用

- 只在当前任务允许的既有型号和模式中选择；适配器存在不等于项目授权调用。用户明确指定模型时，先检查可行性，发现不匹配则说明，不擅自替换。
- 仅对本包有适用依据的具体型号/模式给出适配结论。未维护的版本需独立适配与当前来源，不能用旧版规则代替；不沿用个人白名单、等待策略，也不自动监控、安装或测试。
- 默认以场景或连续镜头组建立主力方案；同组沿用不变条件下的有效结论。只有任务、画风合同/动态规则、参考、版本/模式、重要官方事实、费用约束或实际失败证据变化时复查相关部分，不逐镜重跑完整比较。换画风需要重查受影响的证据和验收，不等于必须换模型。
- 模型不能替代导演选择、剧情、画风或声音归属。一次生成时长上限不是镜头时长目标；不为了迁就模型删动作、拉长一次打击、改对白或静默降低验收标准。
- 模型选择只在视频任务生效。生图、独立音频和普通问答不加载整套分类。只读比较不新建制作记录；实际制作复用获授权的原有计划/操作记录，不强制另建文件。

## 1. 提取决定本段成败的要求

从已批准的剧本/导演/视觉/声音合同提取：本段观众应看懂或感受到什么、哪些关系不可丢、已有素材承担什么、必须到达什么终点。只记录改变选择的维度，不把所有维度等权打分。

| 维度 | 需要区分的要求 |
| --- | --- |
| 表演 | 目光对象、情绪变化与克制程度、脸/呼吸/身体协同、角色间回应；不是单张脸好看 |
| 动作 | 连续运动、速度变化、准确接触、受力后果、高速轮廓；流畅不等于打中，跟随单人参考不等于双人编舞 |
| 摄影与时间 | 摄影机路径与真实视差、构图/焦点、切点、正常速度/升格意图；镜头倾斜不等于环绕 |
| 一致性 | 身份/服装/道具、空间轴线、遮挡前后状态、切镜/接续状态；首帧相似不等于整段稳定 |
| 风格 | 当前合同指定的形状/边缘、材料/笔触、空间、运动节奏与允许变化；某画风的成功不自动证明任何其他画风表现，也不以某一家的专用检查表代替当前合同 |
| 声音 | 说话者/台词/音色/口型、接触声，以及禁止原生生成的声音层；保留原生与后配分开 |
| 可制作性 | 素材和操作是否匹配、当前入口/规格、已知实际费用与修整工作量、组内统一和可剪性 |

把要求分开：**输入/操作硬条件**、**不可降低的成片验收条件**、**可权衡的偏好**。准确受击等成片硬要求，不应被谎称为模型保证，也不因没有保证就一律禁止制作：保留目标，说明风险及实际验收方式。若必须保证的精度已超出可支持路径，则报告缺口，不能用较高综合评价抵消。

### 画风是开放输入，不是预设模型标签

沿用 [开放画风合同](../../visual-design/references/appearance-family-routing.md)，包括自定义与混合媒介；列举的风格不是允许名单。具体合同已明确时不为补分类重复询问。未确定画风的选型讨论可给条件化方案，但不能擅自默认为写实或三渲二；真正制作前仍按既有锁定要求明确。

对每个候选额外判断**当前画风证据适用性**：直接相关 / 仅部分维度可借鉴 / 未知，并指出哪些维度和哪份来源。它与任务适配、证据级别和宿主就绪不同，不是新 API 字段或必填 JSON。综合“表演好”“运动强”只能提供候选线索；除非已知样本/模式/参考/动态要求与本合同相符，不得推成该画风的稳定能力。大类相同也不充分：都是二维，是否允许固定轮廓、顿帧或笔触变化仍可能相反。

缺少画风实证时，可按已确认的控制能力、素材职责和同场景工作条件给**暂定候选**，但要明确“任务控制有依据，画风实现未验证”；不能伪造模型×所有画风评分、降级作品画风或为填表自动付费测试。已批准的参考只提供外观权威，不保证输出动态；若没有候选能满足已知硬条件，说明缺口而非强排。

同一剧情换画风时，保留事件、人物关系和导演意图，重新检查允许的形变/时间表现、摄影空间、声音配合和风格漂移风险。推荐可能改变，也可能仍用同一型号；合格的区别是理由、证据可迁移范围和验收随实际约束变化，而不是为显得适配强制换品牌。混合媒介按层/片段分配这些要求；不将每层自动拆成一次生成，更不默认允许不同镜头随机换风格。

## 2. 先筛可行模式，另查提交就绪

候选最小身份：正式模型/版本与变体 + 任务/输入模式；已知宿主时附实际入口/modelKey。不在整个品牌层面比较互不相容的模式。

- 对素材类型/组合、主体控制、起终帧、声音输入/输出和必要规格逐项核实适用官方依据。明确不支持该组合的模式排除；关键能力未知则标为待核实，不包装为可提交方案。
- 官方支持、当前宿主暴露、实际输出可靠性分别记录。宿主未指定不妨碍模型原生方案；官方有功能但宿主未核实时，标“原生方案可行，提交入口待确认”，不是“模型不支持”。
- 入口明确缺少必需控制时，该宿主路径不可提交；保留原生方法，说明另选已授权路径或改变制作方案的条件。不能偷偷将精确首帧改成普通风格参考。
- 重要能力事实复用 [平台证据规则](platform-routing.md)，必要时运行既有 `platform_evidence_check.py`。其通过只核对证据结构，不证明来源真伪、当前有效性或成片效果。

## 3. 将适配判断和证据充分程度分开

对少数真正可行的候选比较“解决哪个关键问题、付出什么代价”。不是按总分冠军分配所有任务。

- **适配判断：**优先候选 / 可用备选 / 有条件可用 / 不适合此路径 / 暂不能区分。附决定性原因，不编造 92 分、成功概率或精确权重。用户另行要求评分时，也不把判断分冒充测量值。
- **质量证据充分程度：**较充分 / 部分支持 / 不足，并说明适用范围。相近版本/模式/画风/控制条件的实际结果才可增加相关信心；来源数量、官方宣传、榜单第一或一条成功均不能单独判为较充分。
- 外部基准、专业评测、网友案例均保留 `community-observation`，可在其下注明来源类别和方法；专业不等于无商业关系。本项目实际结果须符合 `project-verified` 的素材/哈希/模式/检查范围要求。其他未知仍为 `unknown`，不改变现有证据枚举。
- 比较证据需核对测试日期、确切变体、文生/图生/编辑模式、参考职责、提示词处理、分辨率/时长、首轮还是多次择优、后期、样本量、来源独立性及可访问范围。正文说已测试，不代表本助手看过全部视频。
- 同提示词测试说明该写法下的表现，不一定展示各模型上限；原生优化写法须从同一创作合同独立编译。不同写法、参考或后期同时变化时，不把差异完全归因于模型。
- 冲突证据保留条件，不用帖子票数投票、不平均不同比赛分数。区间重叠、小样本、旧版本或错配任务时，允许无法可靠排序。新版本或新的关键模式需核实，不把画像中的旧观察称为当前事实。
- 条件相近且证据无法区分时，优先保留已批准的同场景方案，减少身份、声音、画风和剪辑衔接风险；其次比较已知的工作量和费用。不默认“先 H3 再 Seedance”，也不默认“文戏/打斗各固定一个品牌”。用户明确的模型锁或专门顺序仍须尊重，不以通用路由擅自覆盖。
- 没有历史可用率时，只报已知报价及潜在返工项，实际可用成本保持未知。既有素材、模式和改动范围均相近且有完整尝试分母时，才可给出带范围的成本/可用率估计；不拿平台订阅价直接换算本项目成片成本。

## 4. 给出简短的选型说明并传给审片

在原有制作计划中保留本次选择快照。可以用自然语言，不是新 API 字段，不需要放入可粘贴提示词。初次选择或实质换模时覆盖以下信息；沿用时只引用有效结论和变化：

1. **范围与关键要求：**哪场/哪组/哪个制作单元，哪些创作锁、画风合同/允许变化及参考版本决定本次选择。
2. **首选：**具体版本/模式；解决什么关键问题，为什么其他主要候选暂不优先。用户已锁模型时说明适配结果，不虚构一次自由选型。
3. **证据与就绪：**支持和反证的来源/日期/适用条件，质量证据充分程度，对当前画风哪些维度直接相关/部分可借鉴/未知，宿主待核项。没有可信胜者时明确说明。
4. **风险与验收：**最可能失败的关系、对应事件/对象/声音、需要的正常播放和重点检查；不能用模型风险清单取代整段审片。
5. **备选及触发：**只有它能针对当前风险提供具体不同的控制/方法才列为备选；说明何种已观察到的问题会触发考虑。没有合理备选就说明缺口，不硬填另一模型。

只读或提示词讨论中可把这几项直接答在对话里，不强制生成计划/报告文件。保持输出与任务规模相称；不为简单镜头写长篇研究报告。

模型更换意味着重新走确切适配器，从同一 source lock 编译；不翻译上一模型提示词，不改变导演/画风/声音合同。相邻镜头组还要核对身份、材质、色彩、运动节奏、声音和接续，不为了单镜优势破坏整体一致。

## 5. 用实际结果校准，不自动消费

审片在既有检查中核对：选型理由预期解决的要求实际通过/失败/未验证了什么，是否出现未预料的缺陷。先执行 [失败归因](../../review-continuity/references/failure-attribution.md)，区分设计、素材、编译、模式/宿主、模型执行和后期；未执行的必要提示、错误绑定或压缩问题不能直接记为模型弱点。

有授权的制作反馈复用原记录，绑定具体型号/模式/宿主、提示词与参考版本、结果路径/哈希、检查区间、成功与失败、累计尝试及已知实际费用。只看图片不能验证动态，只查画面不能验证声音；一条成功不建立通用可靠性，一次失败不建立永久禁用。跨项目迁移不因同名模型自动读取其他项目资料。

换模触发只是**诊断建议**，不是调用授权。服从当前项目的剩余次数、费用、模型范围、暂停及维护边界，不额外创造“选型测试额度”。无生成任务的讨论不触发测试；已接受旧素材不因新画像重做。音轨可修而画面合格时，优先按批准后期方案处理，不自动重生成画面。

普通审片不自动改技能画像。仅在已授权维护时，按 [证据学习规则](../../review-continuity/references/rule-learning-and-validation.md) 将可追溯结果整理成限定范围的经验，保留反例与未测迁移。明确废止过时判断，不无条件追随最新榜单。
