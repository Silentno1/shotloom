# Image platform boundaries

Read only the selected model's adapter and relevant operation. Baseline 2026-10-02 for the three families below: [official source/coverage register](image-model-sources.md). Version-specific methods remain available without a third-party interface; actual submission requires its real bindings and settings. A vendor's latest default never silently replaces a locked model or appearance.

## Midjourney

Use [midjourney.md](midjourney.md): V6/6.1 and Niji 6 Character Reference, V7 Omni, V8.1/8.2 Edit Model, and the distinct Niji 7 writing branch. Image Prompt, Style Reference and identity/edit inputs have different responsibilities; do not interchange them. Parameters remain at the prompt end where supported. Treat precise text and cross-shot identity as review tasks.

## Gemini image / Nano Banana names

Use [nano-banana.md](nano-banana.md): resolve original, Pro, 2 or 2 Lite to the documented model. Generation, reference composition, local edits, style transfer and text localization have different writing contracts. Do not let a style or full-body image override a focused identity authority. Reference-count support is not proof that a lightweight variant is suited to complex sequential edits.

## Kling IMAGE 3.0 / IMAGE 3.0 Omni

Route through [kling-3-series.md](kling-3-series.md) to [kling-3-images.md](kling-3-images.md). Separate ordinary generation/editing from Omni series output; output image count is not reference count. Use static visual contracts, not video timelines. Confirm the image model actually exists on the selected host; do not substitute the video model named O3.

## GPT Image

For GPT Image 2.5 use [gpt-image-25.md](gpt-image-25.md): distinguish Flare/Sunburst, generation/edit paths, reference roles, exact text, transparency and real output controls. Do not transplant earlier-model parameters or claim an unspecified image tool uses 2.5. Other versions require their own current official specifications. Support does not guarantee exact typography, identity or layout.

Never copy one prompt and only replace the model name.

If an exact version or capability remains unverified, keep a generic static visual/edit contract and mark unresolved syntax/settings rather than inventing them. This fallback does not erase confirmed branches. Improve empirically only after reviewing actual outputs from an authorized use; do not auto-generate multi-model comparisons.

Under the shared [appearance activation scope](../../visual-design/references/appearance-family-routing.md), load [three-render-two-compilation.md](three-render-two-compilation.md) for a whole-work contract or only its approved local owner inside `mixed_media`. Compile static dimensions unless the image is explicitly an animation design/keyframe authority. A successful still does not verify cadence, deformation or texture adhesion in motion. Keep the mixed root and other layers unchanged; no extra image operation is required by this local branch.
