# Nano Banana / Gemini Image 生图与编辑

核验基线：2026-10-02。来源、阅读范围与网页差异见 [image-model-sources.md](image-model-sources.md)。不涉及 Veo 或其他谷歌视频生成；图像模型能读取某些视频输入，也不等于本次接入了视频输出模型。

## 别名先解析到型号

| 官方名称 | 当前文档模型 ID | 使用边界 |
| --- | --- | --- |
| Nano Banana | `gemini-2.5-flash-image` | 保留旧项目分支，不承接 3.x 的分辨率、参考与搜索能力 |
| Nano Banana Pro | `gemini-3-pro-image` | 复杂指令、精细设计候选；不是无条件最佳/最低成本承诺 |
| Nano Banana 2 | `gemini-3.1-flash-image` | 多参考与编辑候选；不凭名称保证角色稳定 |
| Nano Banana 2 Lite | `gemini-3.1-flash-lite-image` | 官方定位效率优先，未针对多参考与连续多轮编辑优化 |

宿主只写“香蕉”或“Pro”时，不伪造 exact ID；仍可先写通用意图和待定设置，关键能力需在选定型号上核实。官方推荐迁移不自动覆盖已锁版本。

## 按操作编写，不混成一种句式

| 操作 | 应交给模型的控制信息 |
| --- | --- |
| 从零生成 | 具体主体、可见状态/姿态、环境、相互位置、景别构图、已选媒介及必要光色 |
| 多图组合 | 逐图编号和职责；谁提供身份、谁提供服装/道具、谁提供空间/风格；位置、比例、遮挡、接触、透视和光照如何统一 |
| 加/删/换元素 | 指定基底与目标区域，描述改完的状态和与周边的整合；列出不应变的关键部分 |
| 局部编辑 | 清楚的变化量 + 身份/轮廓/构图等保留项；文字区域描述是语义遮罩，不等于上传像素蒙版或保证区域外逐像素不变 |
| 风格迁移 | 内容/布局保留与媒介/线条/纹理/光色改变分开；不让风格图抢走角色权威 |
| 文字/本地化 | 已批准的精确文案、语言、出现次数、位置层级、字体外观；只翻译获授权部分，不擅改对白或标识 |
| 有搜索依据的制图 | 先明确需检索的事实和来源，再指示其视觉表达；只在该型号及入口支持并启用相应工具时使用 |

使用明确动作动词组织任务，自然语言把对象关系讲清；正向描述空街等目标通常比长否定清单有效。摄影/渲染词只作为已选外观的线索，不把三点布光、浅景深或写实强塞进所有风格。

连续修改时使用最近已验收的基底，优先围绕本次主要变化收敛，重申关键不变项；不凭“跟之前一样”假设宿主持有完整上下文。发现累积漂移应回到合格基底定位原因，不能无限叠加修补与费用。语义蒙版不是像素保护；需要绝对不变区域时说明须另有经授权的合成流程。

## 参考与输出能力的分层

- 3.x 文档总参考上限为 14 张，但角色、物体、风格的描述与各版能力不同。Nano Banana 2 的示例能力为 10 个物体参考/4 个角色参考；Pro 为 6 个物体/5 个角色/3 个风格参考。不要把这些描述当成任何拥挤场景都保真的保证，也不要在总上限之外叠加。
- Lite 表里虽列最多 14 个物体参考，概览仍明确“未针对多参考/连续编辑优化”；数量允许与适合该任务是两回事。其角色/风格栏 N/A 不改写成“完全不认识人脸”。
- 原始 2.5 “最多 3 图效果较好”是建议，不伪造为官方硬上限。身份、正侧背设计图、画风图数量仍取本任务最小充分集。
- Pro / Nano Banana 2 支持的 1K/2K/4K、2 的 512 档，不能移植给仅 1K 的 Lite 或旧 2.5。输出比例/分辨率应走该入口真实设置；“4K”写在正文不等于已应用参数。长宽实际像素随比例变化，检查原文件。
- 搜索 grounding、图片搜索、图片编辑和普通生成分开：Pro/2 的网页搜索能力不外推给所有型号；图片搜索分支也不等同所有版本都支持。引用网址的文本不能自动开启检索；结果中的事实仍要复核。
- 这组图像生成路径不接受音频输入；不能移植 Wan/H3 的音色引用。工具返回的中间图不默认是验收成片，以最终交付图为准。
- 必要文字先在已授权文本阶段确认，再用于生图；不是每次都必须额外调用模型写文案。出图数量可能不精确跟随自然语言要求，实际提交数量与费用仍要核实。

## 自检与适用范围

核对具体型号 → 操作 → 输入职责 → 改动/不变项 → 实际输出设置。验收眼神与肢体、身份、物件接触、文字、图层融合和非目标漂移。手册建议不等于项目验证，不能承诺完美一致。

不复制厂商示例的角色、场景或默认审美，不启用额外搜索/批处理/付费对照作为隐藏默认。型号未证实的功能先保持 unknown，不因某第三方入口缺按钮就从方法库删掉官方能力。
