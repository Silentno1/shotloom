## Four authorities

1. Creative authority: approved story, method, look, dialogue, sound ownership and acceptance criteria.
2. Official model documentation: native task semantics and writing conventions, with requirements separated from recommendations and promotional claims.
3. User destination evidence: actual available inputs/controls when supplied, using [destination bindings](destination-bindings.md); no private snapshot is inherited.
4. Observed result: matched model/variant, inputs, prompt/settings and actually inspected output/range/modalities.

A narrower destination does not erase model documentation; documentation does not prove destination readiness. A static example cannot prove motion, and surviving selected examples cannot establish success rate.

## Cross-model transfer

Carry approved visible/audible meaning through one source lock, then compile each target independently. Keep optional detail separate from exact execution locks. Do not use mixed-model or unmatched examples to derive universal prompt length, model rankings or style guarantees. Model-specific limits and grammar remain unknown where current evidence cannot be established.
