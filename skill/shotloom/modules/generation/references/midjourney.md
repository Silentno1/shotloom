# Midjourney 生图：按版本和参考职责编译

核验基线：2026-10-02。官方来源与差异见 [image-model-sources.md](image-model-sources.md)。仅维护生图/图片编辑，不因网页出现视频功能而扩展到视频。已选模型、导演和外观合同不因版本默认值改变。

## 版本路由

| 已选版本 | 身份/编辑分支 | 编写边界 |
| --- | --- | --- |
| V6 / V6.1 | 旧 Character Reference：`--cref`，`--cw` | 从官方 Legacy Features 查旧规则；不使用 V7 Omni 替代 |
| V7 | Omni Reference：`--oref`，`--ow` | 一张 Omni 图；不是 V8 的多图编辑模式 |
| V8.1 / V8.2 | Edit Model，自然语言编辑/多图组合 | 最多 4 张参考；Discord `--edit`，网页放入对应 Edit 槽位；不沿用 cref/oref |
| Niji 6 | 旧 Character Reference 分支 | 用 `--niji 6`，不可仅因是动漫就默认升级 |
| Niji 7 | Niji 专门写法 + 当前已证实的参考/编辑能力 | 官方发布说明不支持 cref；V7 Omni 不能因数字同为 7 就移植过来 |

V8.0 已退出可选版本，仅用于解释历史素材。官方当前默认 V8.2 不是更改用户锁定版本的授权。更早版本有正式旧项目需求时回查 Legacy Features，不把现代参数外推过去。

## 先分三类参考

- **Image Prompt：**用于内容、构图、配色等引导，不是精确编辑或身份证明。Discord 图片 URL 在正文前，原生参数在正文末；网页使用实际对应槽位。正文描述想得到的最终图，而不是无编辑输入却写“把这里改掉”。
- **Style Reference `--sref`：**传递风格而非复制人物或物件；把媒介、光色、纹理等与身份职责分开。风格码也有版本，不保证跨版本外观一致。
- **Character / Omni / Edit：**按上表选择需要的身份或编辑方法。不同权重不是可互换的“相似度”；增加权重可能压制动作、服装或构图目标。

没有真实参考图时不输出虚假 URL；暂未绑定时把上传计划留在操作说明外，不放进可直接提交的正文。

## 文生图与参考生成

由主体数量与身份、可见动作/姿态、空间关系、景别构图、必要光色和材质组成最短充分描述。具体名词与位置关系优先于堆砌“电影级、史诗级”；短并不等于删掉角色之间的关系或精确设计。图片任务不抄视频时间轴、声景段落或 H3 标签。

姿态写眼神目标、手与物件的接触、身体朝向和画面裁切；不用抽象情绪替代可见行为。必要文字保留精确内容，出图检查拼写。`--no` 用于必要排除，不能以否定已批准画风的词库覆盖项目。

参数与自然描述分开：版本、比例、参考及其权重放在受支持的位置；网页控件不假装是正文。`--raw` 只是减少模型默认美化倾向，不是提高质量的万能开关；stylize、personalization、moodboard 会影响外观，只有符合既有合同才启用。

## 版本专有细节

- V6/Niji 6：`--cw` 0–100，默认 100；低值更聚焦脸，高值包含更多头发/衣着影响。换装时分别说明身份保留与新服装，不许用减小权重代替身份验收。
- V7：`--ow` 1–1000，默认 100；官方建议多数情况低于 400，是经验建议而非硬上限。Omni 与 Draft、Conversational、`--q 4` 及旧局部变化工具存在限制，需核对具体操作。细小雀斑/标识仍可能改变。
- V8 Edit：明确基底、各参考角色、变化目标与保留项；适用于替换/组合、新视角、局部编辑、扩图和重设外观等。首张图默认影响结果比例，需要不同画幅时显式设置。Edit 专页不支持 tile/Remix；不要用主版本总表的 Remix 支持覆盖 Edit 子模式。
- Image Weight 当前专页给 V7/V8.1 0–3、Niji 7 0–2，默认 1；该表未列 V8.2，需查当前该版本说明，不能仅按邻近版本补值。
- Style Reference 的 `--sw` 0–1000，默认 100；`--sv` 是风格参考算法版本，不是主模型版本。V6 常用默认 4，V7 默认 6；旧码的兼容方式只在官方明确版本内使用，不向所有 Niji/V8 推广。
- V8.1/8.2 不支持 `--q`；V6 与 V7 的 q 可选值不同。普通 `::` 多提示权重在 V6 与后代的支持也不同；不可把特定风格参考权重的语法当成通用多提示支持。
- HD/扩图/局部编辑可能改变输出尺寸；标签写 HD 不证明最终文件仍为 HD，验收读实际像素。seed 不锁住人物身份，也不保证像素完全相同。

## Niji 7 写法

官方专门指南强调更按字面理解。需要环境、光照、裁切就显式写清楚，不等待模型替一张人物图自动补出完整场景。全身需求直接写完整身体和双脚可见；鞋子细节可辅助，但不是保证全身的魔法词。

平涂、线条、厚涂、景深等只按已批准外观选择。Niji 默认偏平不意味着项目必须改成平涂；“anime screenshot”、raw 或强光都不能无条件附加。恢复旧版外观可使用已批准旧图的 sref；不为此自动先付费生成一张旧版图。

空镜、道具、远景、反应镜头可按叙事需要保持克制，不把每张都优化成主角宣传海报。模型的强项是可用方法，不是要求全剧一种景别。

## 验收与回退

先检查本张用途需要的身份、服装、几何、构图、文字及非目标区域，再批准为后续视频参考。单张通过不证明跨镜、动作或成片一致。未知版本/编辑入口保留通用静态合同与待核实项，不套另一个版本的伪参数，不自动多版本比图消耗额度。
