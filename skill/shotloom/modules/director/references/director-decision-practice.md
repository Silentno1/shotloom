# 导演方法：从处境到声画选择

用于把已批准的具名参考或自建方法用于具体场景，或做选型研究、维护验收。自建方法直接用下方决策链，跳过人物档案检索；不补造导演来源。不是新制作流程，不要求每场填表、比较多人或生成测试。授权和继承按 [director-selection.md](director-selection.md)。

## 来源、迁移与本片设计分开

用 `scripts/director_methods.py profile ID` 按需读取：[来源目录](director-profiles.json) 中的事实、作品边界、卡片与未有来源覆盖的维度，以及 [条件化应用索引](director-decision-methods.json) 中本技能原创的应用建议。索引覆盖现有 69 档案，**不是新增 69 份已核导演自述**。其 source 指纹用于发现依据变动；失配时重核受影响建议，不以更新公共资料为理由废除真实项目的有效导演锁。

一条音乐资料不能证明该导演的全部表演、镜头和剪辑习惯。先用卡片支持的机制；其他维度从本片剧本与已定方法补足，明确属于本片自主设计。缺证时缩小导演归属主张或定向补证，不伪造全维度专长。未被采用的方法不必硬塞进场景。

参考作品只证明“在什么处境下，这种处理解决了什么问题”。不得把其台词、标志性构图、镜头顺序、固定时长、剧情结局复制成通用配方。导演名字、胶片颗粒、色调和画风不替代方法说明；也不借“导演风格”改原剧本。联合执导仍延期。

## 条件化决策链

对关键处境补齐现有场景/表演契约中的缺项即可：

1. **处境与权限**：人物实际知道什么、想让谁做什么、什么不能暴露；观众已知什么。以权威剧本为准，不猜隐藏动机。
2. **观看任务**：此刻让观众等待、理解、误判、察觉、感受或保持不确定的具体对象是什么？并非每场都要增添新信息。
3. **方法机制**：采用所选参考的哪条有限方法，它怎样服务此处境？哪些选择只是本片设计？
4. **主要载体及配合**：由行动关系、声音、脸/眼神、空间、剪辑或时间处理承担重点；其余有意支持、保持中性或构成可理解的反差，不同时抢峰值。
5. **变化条件**：哪次回应、发现、失败、接触或任务完成使表演策略、镜头或声音改变？若无需变，持续的观看价值是什么？
6. **替代与检验**：更简单的拍法会损失什么？何时应放弃当前手法？正常播放时必须读到什么，又不能被提前说破什么？

“紧张→快切→大声→推近”不是完整决策。隐瞒可能需要连贯等待、稳定构图和平常语气，也可能需要碎片化主观注意；公开危险可能需要清楚的共同空间和简短指令，也可能由快切组织同时威胁。依据是信息、任务与观看立场，不是情绪标签。反例不是另一条固定配方。

## 声音、表演、镜头与时间一起决定

表演由目标与策略驱动，参见 [whole-body-performance.md](whole-body-performance.md)。区分角色稳定音色/口音/说话身份、本场对谁采取的策略、此句可听出的执行。只指定影响理解的重音、停连、语速、音量、呼吸或尾音；正常语气可保留。不要逐字标全部声学参数，不改精确台词，不把配音设成旁白。可听的威胁未必更响，掩饰也不必机械压低嗓音。

把声音和身体放在同一事件线上：角色在对方哪次回应后转移目光、停手、继续原任务或改变说话策略；听者是否能接收到触发；跨切后保留哪些未结束的动作和情绪。允许真情、表面姿态与观众察觉不同，也允许外放、风格化和明确表达，不把“有层次”写成人人克制。

区分至少六个互不等同的节奏：人物动作速度、说话/停顿、画内运动、剪辑频率、故事时间与银幕时间的关系、音乐节拍。只写此次相关的层。快动作可以在稳定长镜头中成立，快速交替可以包裹不动的等待，慢声线可以出现在短促剪辑中；成立与否看整体可读性，不看标签。升格区间按注意价值进入/退出，不给单次击打固定秒数。

镜头须容纳表演载体：关键是手上任务与听者关系时，不能只留说话人的脸；关键是眼神细小转变时，要在最终展示尺寸能读到。调整构图、表演幅度或精确锁的冲突须按已有权限处理，不静默替换。运镜、移焦、切镜与人物位移可以是替代方案，不全叠加。

声音计划先定听点、前后景、重点/静默及连续范围，再逐层决定 native_required / native_optional / post_only / intentional_silence。不能因“紧张”就添加鼓点，因“导演电影感”就要求模型直出整条混音。[transitions-sound.md](transitions-sound.md) 的归属规则不变。后配层不进入画面生成的可听请求；其口型、动作、精确台词和同步锚点依原策略保留。

## 两类纸面对照，按问题触发

**A．同一场景，不同方法**：选型不确定、检验候选是否真正不同或维护能力时使用。先列同一份权威事实/精确台词/人物动机/可知信息/因果/结局/精确锁；候选只变导演有权决定的变量。比较观看立场、表演与配音、调度、景别/运镜、节奏、声音、观众后果、所需素材与风险。不能新增倒计时、秘密、动作结果或改一句台词来证明谁更好。不固定人数，也不逐镜强制比较。已选项目的研究不能偷偷换导演。

**B．同一方法，不同处境**：检验适应性，而非给整个作品强制统一镜头。每个处境各有独立事实锁；比较的是保持了什么观看原则、因为哪些处境变化而换了哪些执行。不是声称两个不同剧情是严格控制的导演效果实验。若只是替换情绪词，镜头、说话方式、切点和声音全部照搬，须说明为何仍适用，否则重写。

默认两类都是纸面、0 次生成。比较文字难易不等于实测成功率，复杂覆盖不自动等于多次生成。Shotloom 不调用外部生成服务；如实际结果有必要，说明待验证的问题和用户需带回的证据，不自行消费或增加重做。见 [纸面对照与反例](director-paper-comparisons.md)。

## 下游只传必要决策

- 给生成：可见/可听事件、变化触发、顺序、终态、必须保留与允许变化、声音归属；通过当前模型官方手册编译。不要把整份研究、导演姓名或解释性心理独白塞入提示词。
- 给剪辑：必须读到的关系、信息边界、动作/声画接点、时间处理意图；实际入出点只能来自已查素材。源片全长不是成片时长。
- 给审片：正常播放能否读到目标作用、是否暴露不该暴露的信息、是否模板化、同一方法在不同处境是否有理由地变化。漂亮单帧、正确术语、程序过关都不证明导演效果。

先判剧本/方法/可读性，再判生成遵循、剪辑组合和实际音画；不要把上游设计不足全归因模型。纸面验收只证明设计足够具体、无明显冲突；情感可信度、打击感和成片观感须实际媒体验证。
