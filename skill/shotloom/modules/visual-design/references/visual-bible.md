# Visual bible

```text
version and authority sources
production method
appearance family and family-contract version
final visual appearance
character shape/line/color/material contracts
environment geometry and surface contracts
light and color hierarchy
camera-space assumptions inherited from direction
motion cadence and deformation
VFX/compositing ownership
text/UI system
controlled sublooks and entry/exit rules
platform upload category record, if known
forbidden drift
representative validation shots
open questions
change log
```

Keep a stable family-level base lock and separate shot/sequence deltas. A delta may emphasize or temporarily alter a dimension, but it must name the trigger, retained invariants and return rule. Do not restate the entire base look in every shot.

Controlled sublooks may change medium or technique for screens, memory, dreams or graphics, but must state boundary, retained anchors and return logic. They do not silently rewrite the main look.

Separate an approved design choice from demonstrated execution. A user may lock a method while motion/performance remain unverified; record those limits rather than fabricating evidence or refusing the creative choice. For authorized validation, select representative cases for the work's actual risks: quiet acting and spatial/action coverage when both matter, but not compulsory actors or action tests for scenery, graphics or static-only work. Reuse adequate existing evidence. A still-image success is not a motion validation; new generation or spending requires its own authorization.
